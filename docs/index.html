EVIDENCE, NOT GUESSWORK

A product name alone is not proof.

Folder matches use the registered app identity. Services, scheduled tasks and startup entries are separate read-only reports; no name match proves ownership.

HONEST LIMITS

A careful tool says what it cannot do.

  • AppX/MSIX listing and removal apply to the current Windows user; other profiles are not managed.
  • Services, scheduled tasks and startup entries are read-only reports. CleanLens does not remove them.
  • Install Monitor watches supported roots only, does not read file contents and may lose events on buffer overflow. Disk totals sum file lengths and can omit unreadable paths.
  • Appearance themes and accessibility validation are still planned.
  • The Windows x64 ZIP is unsigned; no installer or updater is provided.
