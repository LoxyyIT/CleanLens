A CLEARER UNINSTALL

Uninstalling isn't always the last step.

An app can be gone while settings and caches remain. CleanLens makes the next step visible and keeps the decision with you.

CLEANUP WITH GUARDRAILS

Deep clean shouldn't mean blind deletion.

Name matches are only leads. Manual deletion is permanent, opt-in and shows every full path before confirmation.

Read the security boundaries →
01

Preview every path

Review the candidate, its category and why it matched before moving anything.

02

Keep personal data separate

Common personal folders are searched only when you invoke manual delete; matches start unchecked.

03

Move to local quarantine

A selected application-data folder can be moved and restored if its original path is free.

04

Protect system paths

Windows, Program Files, known user libraries and reparse points are refused by cleanup guards.

ROADMAP

EVIDENCE, NOT GUESSWORK

A product name alone is not proof.

A candidate needs context from the registered application identity and a known application-data root. Personal libraries and fuzzy matches stay out of the cleanup list.

Application data candidateExact product folder in AppData or ProgramData; publisher metadata required. Review before quarantine.
MEDIUM
Personal folder or name similarityDocuments, saves and fuzzy matches are never selected or offered by the current scan.
OUT OF SCOPE
The current scanner does not claim coverage of every leftover location.

HONEST LIMITS

A careful tool says what it cannot do.

  • MSIX and Microsoft Store inventory are not implemented.
  • Services, scheduled tasks, startup entries and Registry cleanup are read-only or not yet scanned.
  • The leftover scanner covers a small set of exact application-data folders only.
  • Four-language desktop localization and appearance settings are not implemented yet.
  • A self-contained portable package and real Windows UI validation are still pending.
